# Заявки в IT-отдел

Сайт, через который сотрудники отправляют заявки в IT, и панель, где IT их разбирает.

- `index.html` — форма заявки для сотрудников. Сотрудник получает номер (IT-0001) и видит статус и ответ IT.
- `admin.html` — панель IT по паролю: список заявок, статусы «Новая / В работе / Ждёт / Решена», ответ сотруднику.
- Заявки хранятся в **Google Таблице**. Ей управляет скрипт `apps-script/Code.gs`.
- Сайт лежит на **GitHub Pages** бесплатно. Сервер и включённый компьютер не нужны.

Пока в `config.js` не указан адрес скрипта, сайт работает в **демо-режиме**: заявки хранятся только в браузере, пароль панели `demo`.

---

## Шаг 1. Google Таблица и скрипт (10 минут)

1. Откройте [sheets.new](https://sheets.new) и создайте таблицу, например «Заявки IT».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Код.gs` и вставьте содержимое `apps-script/Code.gs`. Нажмите 💾 (сохранить).
4. Задайте пароль для панели: слева **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**.
   - Свойство: `ADMIN_KEY`
   - Значение: ваш пароль (длинный, не такой, как от почты)
5. Справа вверху **Начать развертывание → Новое развертывание**.
   - Тип (⚙): **Веб-приложение**
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   - Нажмите **Начать развертывание** и разрешите доступ к таблице. Google покажет предупреждение «приложение не проверено»: нажмите **Дополнительно → Перейти к проекту**. Это ваш собственный скрипт.
6. Скопируйте **URL веб-приложения**. Он заканчивается на `/exec`.

## Шаг 2. Подключить сайт к таблице

Откройте `config.js` и вставьте адрес:

```js
API_URL: 'https://script.google.com/macros/s/....../exec',
```

Там же можно поменять `ORG_NAME` (подпись в шапке) и `FALLBACK_CONTACT` (куда звонить, если сайт не работает).

## Шаг 3. Опубликовать на GitHub Pages

1. Войдите на [github.com](https://github.com) и нажмите **New repository**. Имя, например, `it-helpdesk`, тип **Public**. Pages бесплатно работает только с публичными репозиториями.
2. **Add file → Upload files** и перетащите все файлы из этой папки (`index.html`, `admin.html`, `style.css`, `common.js`, `config.js`, `README.md` и папку `apps-script`). Нажмите **Commit changes**.
3. **Settings → Pages**: Source **Deploy from a branch**, Branch **main**, папка **/ (root)**, затем **Save**.
4. Через 1–2 минуты сайт откроется по адресу:
   - для сотрудников: `https://ВАШ-ЛОГИН.github.io/it-helpdesk/`
   - для вас: `https://ВАШ-ЛОГИН.github.io/it-helpdesk/admin.html`

Ссылку для сотрудников можно разослать или сделать ярлык на рабочем столе.

## Если вы поменяли `Code.gs`

Apps Script сам не обновляет опубликованную версию. Откройте **Начать развертывание → Управление развертываниями → ✏ → Версия: Новая версия → Развернуть**. Адрес `/exec` останется прежним.

## Что важно знать

- **Пароль не хранится на GitHub.** Он лежит только в свойствах скрипта Google, поэтому файлы репозитория можно спокойно держать публичными.
- **Форму видит любой, у кого есть ссылка.** Если начнётся спам, поменяйте адрес развертывания (новое развертывание и новый `API_URL`).
- **По номеру заявки** видны только тема, статус и ответ IT. Имя, кабинет и телефон видны только в панели.
- Все заявки видны в Google Таблице. Их можно сортировать, фильтровать и выгружать в Excel.
